# 山域輕量化模組裝 · 個人輕量化裝備

一套「個人即公裝」的山域輕量化模組裝互動教學簡報（Reveal.js + Firebase 即時互動）。

## 內容大綱
1. 封面
2. 一般型戶外活動（玩水型溯溪／登山健行／越野跑）— 破冰即時投票（可複選＋自訂）
3. 技術型活動（皆離不開上升與下降）
4. 核心觀念：技術不離開「上升 ↔ 下降」的繩索通過
5. 你願意背幾公斤？— 即時文字雲 → 揭曉個人裝備 2.4–3.2kg
6. 團隊拯救技術
7. 團隊拖拉裝備要幾公斤？— 即時文字雲 → 揭曉公裝重量
8. 輕量化原則＋個人核心觀念
9. 拖拉系統模組 ① ATC-P
10. 拖拉系統模組 ② RPM
11. 個人裝備核心一覽表（可切情境的互動表格＋重量圖表）→ 向下嵌入「滑輪拖拉省力比」互動計算器
12. 團體裝備清單與功能（山域搜救）
13. 各式擔架（SKED／SLIX／RollUP）
14. 結語＋全域匿名提問牆

## 互動教學工具
- 破冰即時投票（可複選、可自訂）
- 兩組即時文字雲（個人／團隊願意背幾公斤）
- 全域匿名提問牆（每頁左側可拉開，可按讚排序）
- Chart.js 互動重量圖表
- 可依情境切換的個人裝備明細表
- 內嵌滑輪拖拉省力比計算器

皆以 Firebase Firestore 即時同步，資料命名空間 `mtn_lightgear_2026`（與其他簡報互不干擾）。

## 導覽
- 主線用 ← → 換頁
- 插圖頁按一下 → 先收起說明卡、再按一下才換頁
- 有 ↓ 提示的頁面按下鍵看互動／滑輪計算器
- 左側 🙋 把手可隨時拉開匿名提問牆

## 技術
Reveal.js 5.1 · Chart.js 4.4 · wordcloud2 · Firebase 11 — 純前端、無需後端伺服器。
